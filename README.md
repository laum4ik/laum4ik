## Projekty

### Asystent Remontowy AI / FlowMate AI

MVP aplikacji SaaS dla firm remontowo-budowlanych do obsługi zapytań klientów z e-maila w jednym panelu.
System:
- odbiera wiadomości z Gmaila przez Make.com,
- zapisuje i klasyfikuje zgłoszenia,
- wykorzystuje OpenAI API do generowania odpowiedzi,
- pozwala właścicielowi zarządzać rozmowami w panelu,
- wysyła odpowiedzi do klienta w tym samym wątku Gmail,
- obsługuje follow-upy i statusy zgłoszeń.
  
Technologie:
Next.js, React, TypeScript, Tailwind CSS, Prisma, PostgreSQL, Railway, OpenAI API, Make.com, Gmail, Webhooks.

Strona:
https://asystentremontowy.pl

### Telefoniczny asystent AI

Projekt automatycznego asystenta telefonicznego dla lokalnych firm usługowych.
System:
- odbiera połączenia telefoniczne,
- prowadzi rozmowę głosową z klientem,
- rozpoznaje intencje klienta,
- sprawdza wolne terminy,
- zapisuje wizyty w Google Calendar,
- wysyła potwierdzenia SMS.

Technologie:
Node.js, Express.js, WebSocket, Twilio Voice, Twilio SMS, OpenAI API, Google Calendar API, Railway.
